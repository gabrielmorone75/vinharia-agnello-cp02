# Vinharia Agnello

Projeto acadêmico de um site para uma vinharia, com informações sobre a loja, produtos e dicas de harmonização.

## Páginas
- `index.html`: página inicial.
- `src/pages/historia.html`: história da vinharia.
- `src/pages/produtos.html`: tipos de vinhos.
- `src/pages/harmonizacao.html`: dicas de harmonização.
- `src/pages/contato.html`: formulário demonstrativo de contato (não envia mensagens).

Os estilos ficam em `src/css/style.css` e `src/css/efeitos.css`.

## Efeitos Visuais
No Check-Point 02 adicionamos efeitos simples usando CSS:
- `:hover` muda a cor dos links e destaca os cartões e botões.
- `:focus` destaca os campos do formulário.
- `:nth-child(even)` muda o fundo dos cartões pares.
- `::before` coloca um detalhe antes dos títulos.
- `::after` cria uma linha abaixo dos links do menu.
- `@keyframes aparecer` faz o conteúdo surgir suavemente.
- `translateY()` movimenta os cartões e `scale()` aumenta um pouco os botões.
- `transition` suaviza as mudanças.

O arquivo `efeitos.css` é importado no final de `style.css`.
